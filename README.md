# QTrobot Storytelling Experiment

## Project Overview

This project was developed for my MSc Creative Robotics final project at the University of the Arts London.

It explores how different waiting times after a storytelling robot's questions affect users' self-initiated verbal participation and perceived opportunities to express their ideas.

## Experimental Design

The experiment involved 32 adult participants interacting with a physical QTrobot.

- Three waiting times: 4, 7, and 10 seconds.
- Each participant experienced all three waiting times.
- Two facial expression conditions: smiling and non-smiling.
- A short interactive story with three questions.

## Robot Interaction

After asking a question, the robot waits for the participant to respond.

If the participant starts speaking, the follow-up reminder is cancelled.

If no response is detected, the robot offers more time and waits again.

The program records response timing, answer duration, and response status.
